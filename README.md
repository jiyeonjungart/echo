# Echo — story reader prototype

A React prototype of **Echo**, a companion app for a bilingual (English and Korean) storybook player.
Families add their own voices to *The Tiger and the Dried Persimmon* (호랑이와 곶감) and sync the book to the player.

This repository is the finished website, flat: `index.html`, `app.js`, `index.css`, the illustrations and the narration
all sit side by side. Turn on GitHub Pages (Settings → Pages → Deploy from a branch → `main` / `(root)`)
and the app opens at `https://<your-user>.github.io/<repo-name>/`. The microphone only works on `https://` pages or `localhost`.

Default narration: AI-generated with Chatterbox Multilingual (Resemble AI, MIT license).
Korean fonts: 학교안심 그림일기 (KERIS, SIL OFL) and KCC간판체 (Korea Copyright Commission, CC BY: credit required).
